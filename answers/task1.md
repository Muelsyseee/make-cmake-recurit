# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理：处理.c源文件中的头文件包含（将头文件中需要的内容纳入预处理之后的代码）、宏展开、条件编译（根据条件决定保留参与后续编译的代码）等预处理指令，形成预处理后的.i文件
2. 编译：把.i文件中的C语言代码编译成汇编语言，生成.s文件，同时进行语法、类型等检查，具体包括词法语法分析等以及代码优化
3. 汇编：把汇编语言转换为CPU能够处理的机器代码以及后续链接所需的信息，得到.o目标文件（还不能直接运行）
4. 链接：把不同的.o文件以及库连接起来，解决不同文件之间的引用并确定最终地址，形成最终的可执行文件

建议控制在 300～500 字，不需要展开复杂细节。
